# Postman API Collection

Import qa-demo-api.postman_collection.json into Postman. The collection includes a positive GET contract, a not-found negative case, and a POST create-request check against JSONPlaceholder. Run it with the Collection Runner or Newman.

The service is a public fake REST API. POST responses are simulated and should not be treated as durable persistence. Change the baseUrl collection variable only to an API you own or are authorized to test.
